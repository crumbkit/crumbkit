Measure the bytes that an agent reads on each path through a tool's help

Usage: cargo crumbkit weigh [OPTIONS] --bin <NAME>

Options:
      --bin <NAME>     Build this binary of the current workspace and weigh its help
      --goldens <DIR>  Read the examples' golden files from this directory [default: tests/golden/examples in the binary's package]
  -h, --help           Print help (see more with '--help')

Examples:
  cargo crumbkit weigh --bin shelf
  cargo crumbkit weigh --bin shelf --json

Global flags: --json, --fields <FIELD>, --long, --full. `cargo crumbkit weigh --help` describes them.
