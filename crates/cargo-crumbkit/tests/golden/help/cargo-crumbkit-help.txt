Measure and explore tools built with crumbkit

Usage: cargo crumbkit [OPTIONS] <COMMAND>

Measure a tool's help
  weigh     Measure the bytes that an agent reads on each path through a tool's help

Write a tool's reference
  docs      Write a Markdown reference of every command of a tool to a file

Explore the commands
  commands  Explore cargo crumbkit's commands

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Topics: exit-codes. `cargo crumbkit help <TOPIC>` prints one.
