Cargo subcommands for tools built with crumbkit

Usage: cargo [OPTIONS] <COMMAND>

Commands:
  crumbkit  Measure and explore tools built with crumbkit

Options:
      --json
          Print the result as a JSON document on one line

      --fields <FIELD>
          Print only these comma-separated fields, in this order

      --long
          Add the long columns after the compact ones

      --full
          With --json, print every field of every row

  -h, --help
          Print help (see a summary with '-h')

Topics: exit-codes. `cargo help <TOPIC>` prints one.
