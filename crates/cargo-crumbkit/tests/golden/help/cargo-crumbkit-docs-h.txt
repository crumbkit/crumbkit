Write a Markdown reference of every command of a tool to a file

Usage: cargo crumbkit docs [OPTIONS] --bin <NAME>

Options:
      --bin <NAME>  Build this binary of the current workspace and describe its commands
      --out <FILE>  Write the reference to this file [default: docs/commands.md in the binary's package]
  -h, --help        Print help (see more with '--help')

Examples:
  cargo crumbkit docs --bin shelf

Effects: additive, idempotent, closed-world.
Global flags: --json. `cargo crumbkit docs --help` describes them.
