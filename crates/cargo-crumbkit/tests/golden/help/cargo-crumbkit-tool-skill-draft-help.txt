Write the generated sections of a tool's SKILL.md from its commands and exported usage

Usage: cargo crumbkit tool-skill draft [OPTIONS] --bin <NAME>

Options:
      --bin <NAME>
          Build this binary of the current workspace and draft its skill from its commands

      --json
          Print the result as a JSON document. The default prints text.

      --skill <FILE>
          Draft this Markdown file [default: skill/SKILL.md in the binary's package]

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --usage <DIR>
          Rank the most-used commands from the exported usage files (*.jsonl) under this directory

      --top <N>
          List at most this many commands in the most-used section
          
          [default: 10]

      --check
          Write nothing, and exit with 1 when a draft would change a section

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

  -h, --help
          Print help (see a summary with '-h')

Examples:
  cargo crumbkit tool-skill draft --bin shelf --skill tests/fixtures/shelf-skill-drafted.md --usage tests/fixtures/shelf-usage-export --check
          Check that a skill file holds the sections that a draft from usage writes

  cargo crumbkit tool-skill draft --bin shelf --skill tests/fixtures/shelf-skill-drafted.md --check --json
          Check the sections without usage, which keeps the usage section

Columns:
  section  The section's name: description, jobs or usage.
  status   What the draft did: written, unchanged, would-change under --check, kept without usage, or unmarked when the file has no markers for the section.

Effects: additive, idempotent, closed-world.
