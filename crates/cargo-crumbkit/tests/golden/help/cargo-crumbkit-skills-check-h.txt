Check that each installed copy of cargo crumbkit's skill matches this cargo crumbkit

Usage: cargo crumbkit skills check [OPTIONS]

Options:
      --dir <DIR>  Check this skills directory in place of the agent skills directories
  -h, --help       Print help (see more with '--help')

Examples:
  cargo crumbkit skills check

Effects: read-only, closed-world.
Rows: the default text lists only the rows that report a problem, and --long, --fields or --json lists every row.
Global flags: --json, --fields <FIELD>, --long, --full. `cargo crumbkit skills check --help` describes them.
Next: cargo crumbkit skills check --help explains each column.
