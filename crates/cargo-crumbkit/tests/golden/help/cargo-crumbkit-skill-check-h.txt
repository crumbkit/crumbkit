Check that every command line in a tool's SKILL.md names its real commands and flags

Usage: cargo crumbkit skill check [OPTIONS] --bin <NAME>

Options:
      --bin <NAME>    Build this binary of the current workspace and check its skill against its commands
      --skill <FILE>  Check this Markdown file [default: skill/SKILL.md in the binary's package]
  -h, --help          Print help (see more with '--help')

Examples:
  cargo crumbkit skill check --bin shelf --skill tests/fixtures/shelf-skill.md

Text: one line per row, <FILE>:<LINE>: <SPAN>: <REASON>; --fields and --long print a table.
Problems: a value in the reason column marks a row with a problem, and the command then exits with 1.
Rows: the default text lists only the rows that report a problem, and --long, --fields or --json lists every row.
Global flags: --json, --fields <FIELD>, --long, --full. `cargo crumbkit skill check --help` describes them.
Next: cargo crumbkit skill check --help explains each column.
