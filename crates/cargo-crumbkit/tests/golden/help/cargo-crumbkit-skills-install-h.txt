Install cargo crumbkit's skill into each agent skills directory that exists

Usage: cargo crumbkit skills install [OPTIONS]

Options:
      --dir <DIR>  Install into this skills directory in place of the agent skills directories
      --force      Replace a file or a link that install did not write with the skill's own folder
  -h, --help       Print help (see more with '--help')

Examples:
  cargo crumbkit skills install
  cargo crumbkit skills install --force

Effects: additive, idempotent, closed-world.
Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `cargo crumbkit skills install --help` describes them.
Next: cargo crumbkit skills install --help explains each column.
