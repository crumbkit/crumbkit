Check that every command line in a tool's SKILL.md names its real commands and flags

Usage: cargo crumbkit tool-skill check [OPTIONS] --bin <NAME>

Options:
      --bin <NAME>
          Build this binary of the current workspace and check its skill against its commands

      --json
          Print the result as a JSON document. The default prints text.

      --skill <FILE>
          Check this Markdown file [default: skill/SKILL.md in the binary's package]

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

  -h, --help
          Print help (see a summary with '-h')

Examples:
  cargo crumbkit tool-skill check --bin shelf --skill tests/fixtures/shelf-skill.md
          Check every shelf command line in a skill file

Columns:
  file    The path of the skill file.
  line    The line of the skill file that holds the command line, counted from 1.
  span    The command line as the skill file writes it.
  reason  Why the command line does not match the tool's commands, or null when it matches.

Text: one line per row, <FILE>:<LINE>: <SPAN>: <REASON>; --fields and --long print a table.
Problems: a value in the reason column marks a row with a problem, and the command then exits with 1.
Rows: the default text lists only the rows that report a problem, and --long, --fields or --json lists every row.
