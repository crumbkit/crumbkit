PATH                             ABOUT
cargo                            Cargo subcommands for tools built with crumbkit
cargo crumbkit                   Measure and explore tools built with crumbkit
cargo crumbkit weigh             Measure the bytes that an agent reads on each path through a tool's help
cargo crumbkit docs              Write a Markdown reference of every command of a tool to a file
cargo crumbkit tool-skill        Draft and check a tool's agent skill
cargo crumbkit tool-skill check  Check that every command line in a tool's SKILL.md names its real commands and flags
cargo crumbkit tool-skill draft  Write the generated sections of a tool's SKILL.md from its commands and exported usage
cargo crumbkit skills            Install cargo crumbkit's own skill
cargo crumbkit skills install    Install cargo crumbkit's skill into each agent skills directory that exists
cargo crumbkit skills check      Check that each installed copy of cargo crumbkit's skill matches this cargo crumbkit
cargo crumbkit skills print      Print cargo crumbkit's skill
cargo crumbkit commands          Explore cargo crumbkit's commands
cargo crumbkit commands list     List a branch of cargo crumbkit's commands with their arguments, examples and columns
