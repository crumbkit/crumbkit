# crumbkit documentation

- [Getting started](tutorial.md) takes a clap tool to crumbkit in four
  steps, from `parse` and `finish` to convention tests.
- [Behaviour](behaviour/README.md) describes what crumbkit does for a
  tool, topic by topic, and links to the rustdoc of each item.
- [Project](project/README.md) describes how the repository is laid out,
  checked, tested and released.
- [Decisions](decisions/README.md) records each choice that shapes crumbkit's
  code or what adopters must accept, with the alternatives that were
  considered.
- [Standards](standards/README.md) lists the rules that crumbkit's code and
  docs follow, and the lint, check or review that enforces each one.

Each fact in these docs, the READMEs, the changelog and the rustdoc has one
home, which [Documentation](project/documentation.md) names.
