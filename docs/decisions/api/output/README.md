# ADR-0031. Output

These records decide how a tool prints a command's result: the compact text table, the JSON document, the columns that a row type names, the failures, batches and listings that print beside the rows, the failure forms that a tool sets in place of crumbkit's failure document, the streams that print rows as they arrive, and the child processes that a command hands the terminal to.
