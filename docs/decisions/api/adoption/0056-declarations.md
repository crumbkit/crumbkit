# ADR-0056. Declarations

- crumbkit enforces behaviour and lets a tool declare its own names. Behaviour is what an agent relies on across tools, such as when a failure happens, its recovery, the output budget, paging, confirmation and one meaning for each exit code. A name is a word the tool's own users already read, such as a failure code or an exit code, and a tool that declares its own name keeps crumbkit's behaviour, so a declaration needs no reason and no opt-out.
- A tool declares its names through seams. `Guide::codes` lists [`Rename`](../../../../crates/crumbkit/src/help/rename.rs) values, each of which prints the tool's code in place of one of crumbkit's in text, in JSON, in the usage log and in the mark of a cut result. `Guide::exits` may list one of crumbkit's codes or the tool's rename of it, so a refused command line, an over-budget failure or a version conflict exits with the tool's own code (ADR-0002, ADR-0037). A leaf that passes on a program's exit code declares it with `Leaf::passes_on_exit`, which help prints (ADR-0042). `crumbkit::complete_with` declares the name of the completion variable, which the registration script and the usage log then use (ADR-0048). `Leaf::refusal_alternatives` declares calls that a refusal of the leaf's command line offers after crumbkit's own alternatives, and `check_guide` fails on a call that does not render (ADR-0001). A tool that declares nothing prints crumbkit's codes and exits with crumbkit's defaults.
- Each check reads through the seams. `Guide::printed` returns the code that a run prints for one of crumbkit's codes, and `Guide::failure_exit` returns the exit code a failure ends the run with, so `check_exit_codes`, `check_twins`, `check_recoveries` and `check_output_budget` expect what the run prints.
- crumbkit-test's `check_opt_outs` lists each declaration under the customisations of the opt-out report, with no reason and no cost, so a reviewer sees in one place how far a tool has moved from crumbkit's defaults (ADR-0036). A failure form is a declaration too (ADR-0045), and so is a document whose name is not its command's path (ADR-0035). The report does not list the completion variable, because `complete_with` sets it for the process and the guide does not hold it.
- A new seam needs a name that the existing seams cannot declare. A departure from behaviour stays an opt-out with a stated reason (ADR-0036).

Considered: renames held in `Spelling`, a trait that the tool implements to map each code and exit, an over-budget code on each `Document`, renames recorded as opt-outs with a reason, a function on the guide that builds refusal alternatives from each refusal.
