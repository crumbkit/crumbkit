# ADR-0025. Help checks

- crumbkit-test's [`check_help_sizes`](../../../../crates/crumbkit-test/src/sizes.rs) and [`check_help_goldens`](../../../../crates/crumbkit-test/src/goldens.rs) read the help pages that crumbkit prints, by running `crumbkit::parse_to` in memory on a clone of the tree. A page is therefore the plain text that a caller reads on a pipe, with every line crumbkit adds except the line that names a person's aliases, which differs between machines (ADR-0027).
- The help checks skip hidden commands, because no help page shows them. They take budgets in place of opt-outs, because a tool sets a budget per command and pins every page.
- A budget counts the bytes of the plain-text `-h` page, which agents read first and most often. `--help` has no budget, because a caller asks for it to read the full descriptions and the columns. The default budgets are 1,500 bytes for the root, 800 for a group, which is a command below the root with subcommands, and 1,200 for a leaf, which is a command below the root without subcommands.
- A tool can raise or lower any budget with [`Budgets`](../../../../crates/crumbkit-test/src/sizes.rs) and [`PathBudgets`](../../../../crates/crumbkit-test/src/weights.rs), and gives a reason for each budget it sets, so crumbkit's defaults fit most tools and a tool with larger pages can still adopt the checks. `check_opt_outs` lists each budget that a tool set with its reason, crumbkit's default and the extra bytes and tokens of a raised budget (ADR-0036).
- crumbkit-test's [`check_path_weights`](../../../../crates/crumbkit-test/src/weights.rs) budgets each path, which is every `-h` page from the root down to a command plus the command's output weight, the size of the largest golden file of its examples (ADR-0033). The default budget is 8,000 bytes, about 2,000 tokens at 4 bytes a token. A depth-2 leaf at its default page budgets reads 3,500 bytes of help, so 8,000 bytes leaves 4,500 bytes for output. A tool can set the budget of every path or of single commands. shelf lowers its paths to 4,300 bytes. A command without an example golden file, such as one whose examples an opt-out skips, counts 0 bytes of output.
- `check_path_weights` is a check of its own, because it reads golden files, and `check_help_sizes` reads only memory. It sums the paths with the same `path_totals` and `output_weight` functions that `cargo crumbkit weigh` calls, so the check and `weigh` agree whenever the in-process pages equal the binary's pages. A cargo-crumbkit test compares weigh's `short_help` values for shelf with the sizes of shelf's help golden files.
- `check_help_goldens` compares each page with a golden file through snapbox (ADR-0004). It fails on a stale file, so the directory holds only help golden files.
- `check_guide` holds the leaf rules (ADR-0024). [`check_exit_codes`](../../../../crates/crumbkit-test/src/exits.rs) checks the declared exit codes (ADR-0037) as a check of its own, because it takes opt-outs and `check_guide` does not.
- crumbkit-test has no bundled check that runs every check. Each check has its own settings and a tool calls each from its own `#[test]`, so a failure names the rule that broke. By the same rule, `check_document_ids` and `check_mounts` are separate checks (ADR-0035): a wrong document name is fixed by renaming the document, and a crumbkit command at the wrong path is fixed by moving the command.
- `check_output_budget` runs each `--json` example with half the bytes it prints and checks that the tool cuts or refuses the result as crumbkit does. It is a check of its own beside `check_examples`, because it runs each example twice (ADR-0046).

Considered: measuring clap's `render_help` after `extend`, a plain `&[(path, bytes)]` slice of node budgets, a budget on `--help`, leaf rules in a separate `check_leaves`, a bundled `check(command, guide)`, path budgets in `Budgets` and `check_help_sizes`, a budget on output weight alone, a default path budget of 6,000 bytes, a budget that a tool cannot raise.
