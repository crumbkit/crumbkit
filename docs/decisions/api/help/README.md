# ADR-0022. Help

These records decide what a tool's help shows and how a caller reaches it: the lines crumbkit adds to clap's help pages, goal headings, the message of a refused command line, crumbkit's own `help` command, the help topics that a tool declares, the examples and column descriptions of leaf commands, the export of a branch of commands with their arguments, and the checks of a tool's help pages.
