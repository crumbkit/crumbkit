# ADR-0022. Help

These records decide what a tool's help shows and how a caller reaches it: the lines crumbkit adds to clap's help pages, goal headings, the message of a refused command line, crumbkit's own `help` command, the help topics that a tool declares, and the examples and column descriptions of leaf commands.
