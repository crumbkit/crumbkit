# ADR-0003. Dependencies and MSRV

- A dependency needs active maintainers, judged case by case, a compatible `rust-version` and licence, a measured weight, and no async runtime or C build. `Cargo.toml` states its reason and sets `default-features = false`, and a published crate enables only the features its own code uses, so that binaries choose features such as clap's colour.
- The default build depends on clap, serde, serde_json and schemars, and `Cargo.toml` names each dependency, feature and dev-dependency with its reason. crumbkit-core depends only on serde and schemars, so a crate that uses crumbkit-core alone builds no clap (ADR-0032). crumbkit enables clap's `help` feature, so every tool built with crumbkit has `-h` and `--help`, which crumbkit's refusals tell the caller to run. The usage log's dependencies sit behind the `usage-log` cargo feature (ADR-0029), and miette sits behind the `miette` feature with no miette features, because crumbkit draws the source line and its underline itself. The `tracing` feature adds the tracing crate with no features, which has no build script, compiles in about 0.3 s and adds about 18 KB to shelf's stripped release binary (ADR-0030). crumbkit-aliases is a separate published crate, so only a tool with personal aliases builds toml (ADR-0027). cargo-crumbkit depends on etcetera, which the `usage-log` feature already uses, so `weigh --usage` finds a tool's log with the same call that wrote it (ADR-0033).
- crumbkit raises the MSRV of RUST-9 only when a change needs it, never above the newest stable release that is at least six months old.
- crumbkit supports Linux and macOS.

Considered: tabled, comfy-table, ctrlc, dirs, blake3, jiff, hmac with sha2 and getrandom, the usage log in the default build, miette's `derive` and `fancy` features, tracing-subscriber for the span tests.
