# ADR-0003. Dependencies and MSRV

- A dependency needs active maintainers, judged case by case, a compatible `rust-version` and licence, a measured weight, and no async runtime or C build. `Cargo.toml` states its reason and sets `default-features = false`, except for gungraun, which exports its benchmark API only under its default feature, and a published crate enables only the features its own code uses, so that binaries choose features such as clap's colour.
- The default build depends on clap, serde, serde_json, schemars and is-ai-agent, and `Cargo.toml` names each dependency, feature and dev-dependency with its reason. crumbkit-core depends only on serde and schemars, so a crate that uses crumbkit-core alone builds no clap (ADR-0032). crumbkit enables clap's `help` feature, so every tool built with crumbkit has `-h` and `--help`, which crumbkit's refusals tell the caller to run. crumbkit also enables clap's `error-context` feature, so a refusal reads the refused argument, value and subcommand from clap's error for its fields (ADR-0001). The feature adds 33,456 bytes to shelf's stripped release binary on aarch64 macOS, which is 2,494,792 bytes with it and 2,461,336 without it, and clap's `suggestions` feature already turns it on. The usage log's dependencies sit behind the `usage-log` cargo feature (ADR-0029), and miette sits behind the `miette` feature with no miette features, because crumbkit draws the source line and its underline itself. The `hand-over` feature adds signal-hook, which the usage log also uses, so a tool can hand the terminal to a child while the tool ignores Ctrl-C (ADR-0042). On Windows the `usage-log` feature also adds getrandom, which proptest already brings into the lock file, because Windows has no `/dev/urandom` (ADR-0029). The `tracing` feature adds the tracing crate with no features, which has no build script, compiles in about 0.3 s and adds about 18 KB to shelf's stripped release binary (ADR-0030). The `complete` feature adds clap_complete with its `unstable-dynamic` feature, which brings shlex and is_executable and turns on clap's `unstable-ext`, so a tool answers shell completion from the tree it parses (ADR-0048). It adds 102,192 bytes to shelf's stripped release binary on aarch64 macOS, which is 2,614,232 bytes with it and 2,512,040 without it. is-ai-agent has no dependencies of its own, and crumbkit reads it only when a question is about to be asked, so a tool does not ask an agent a question it cannot answer (ADR-0043). crumbkit-aliases is a separate published crate, so only a tool with personal aliases builds toml (ADR-0027). crumbkit-picker is a separate published crate that uses the standard library alone, so a tool that wants a picker with a terminal library chooses and builds that library itself (ADR-0043). cargo-crumbkit depends on etcetera, which the `usage-log` feature already uses, so `weigh --usage` finds a tool's log with the same calls that wrote it (ADR-0033).
- crumbkit raises the MSRV of RUST-9 only when a change needs it, never above the newest stable release that is at least six months old.
- Linux and macOS are tier 1: every pull request runs the full lane on Linux, and each push to `main` runs the tests on macOS (ADR-0011). Windows on `x86_64-pc-windows-msvc` is tier 2: the scheduled lane builds, lints and tests the workspace there each night that `main` changed (CI-4), a failure opens or comments on the scheduled issue, and no release waits for it. Other targets are untested, and the `usage-log` feature refuses to build on a target that is neither Unix nor Windows.
- Windows at tier 2 has these limits. `help::quote` quotes for a POSIX shell, so an example line pasted into PowerShell or `cmd` may need other quoting (ADR-0024). The usage log's directory and files inherit the access control list of `%LOCALAPPDATA%` in place of Unix modes. Closing the console, logging off and shutting down end a tool with no usage line and end a tool beside its child, and Ctrl-Break ends a tool with no usage line (ADR-0029, ADR-0042).

Considered: tabled, comfy-table, ctrlc, dirs, blake3, jiff, hmac with sha2 and getrandom, the usage log in the default build, is-ai-agent behind a feature, crossterm, inquire or dialoguer in crumbkit-picker, miette's `derive` and `fancy` features, tracing-subscriber for the span tests, Windows at tier 1 with a job in the pull-request lane, the GNU Windows target, `windows-sys` for a console control handler, `ctrlc` for Windows Ctrl-C, completion scripts generated at build time with clap_complete's stable API.
