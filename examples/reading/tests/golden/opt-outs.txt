reading has 5 opt-outs from crumbkit's conventions.

examples/run: reading finished edit
  Reason: edit hands the terminal to the caller's editor, which waits for a person and prints no output to compare
  Cost: The examples are not run, so help can show an example that fails.
  Cost: The command's output weight counts 0 bytes, so its path weight is too low.

examples/run: reading to-read edit
  Reason: edit hands the terminal to the caller's editor, which waits for a person and prints no output to compare
  Cost: The examples are not run, so help can show an example that fails.
  Cost: The command's output weight counts 0 bytes, so its path weight is too low.

effects/yes: reading finished edit
  Reason: the person in the editor chooses whether to save the list, so there is nothing for --yes to confirm
  Cost: An agent without a terminal cannot run the command, or the command runs without asking anyone.

effects/yes: reading to-read edit
  Reason: the person in the editor chooses whether to save the list, so there is nothing for --yes to confirm
  Cost: An agent without a terminal cannot run the command, or the command runs without asking anyone.

path-budget/path: every path through reading
  Budget: 3500 bytes, where crumbkit's default is 8000 bytes.
  Reason: reading's longest path, commands list, reads about 3,200 bytes, so 3,500 bytes leaves room for small changes and catches a page or an output that grows by much.
  Cost: None, because the budget is at or below crumbkit's default.
