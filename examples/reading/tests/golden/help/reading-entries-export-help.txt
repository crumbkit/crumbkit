Print the file of the reading list that --list names, as the file holds it

Usage: reading entries export [OPTIONS] --list <NAME>

Options:
      --list <NAME>
          The name of the reading list, such as to-read

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  reading entries export --list to-read
          Print the file of the to-read list

  reading entries export --list to-read --json
          Print the file of the to-read list as JSON text, or as base64 when it is not UTF-8

  reading entries export --list scanned --json
          Print the file of the scanned list, which is not UTF-8, as base64

Effects: read-only, closed-world.
Output: the bytes unchanged, and --json prints them as text or base64.
