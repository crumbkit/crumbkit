Keep reading lists, and print the entries of each

Usage: reading [OPTIONS] <COMMAND>

Commands:
  entries   Work with the entries of any reading list
  commands  Explore reading's commands
  schemas   Explore the JSON documents that reading prints
  finished  Books finished this year
  to-read   Books to read next

Options:
  -h, --help     Print help (see more with '--help')
  -V, --version  Print version

Global flags: --json, --fields <FIELD>, --long, --full. `reading --help` describes them.
Topics: exit-codes. `reading help <TOPIC>` prints one.
