Work with the entries of any reading list

Usage: reading entries [OPTIONS] <COMMAND>

Commands:
  list    List the entries of the reading list that --list names, in file order
  stream  Print each entry of the reading list that --list names as reading reads it

Options:
      --json
          Print the result as a JSON document on one line

      --fields <FIELD>
          Print only these comma-separated fields, in this order

      --long
          Add the long columns after the compact ones

      --full
          With --json, print every field of every row

  -h, --help
          Print help (see a summary with '-h')
