List the entries of this reading list, in file order

Usage: reading finished list [OPTIONS]

Options:
      --limit <N>
          Print at most this many rows
          
          [default: 3]

      --all
          Print every row

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  reading finished list
          Print the first page of the finished list

  reading finished list --all
          Print every entry of the finished list

Columns:
  position  The entry's position in the list, counting from 1.
  title     The title of the book.

Effects: read-only, closed-world.
