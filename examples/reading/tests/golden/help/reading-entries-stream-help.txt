Print each entry of the reading list that --list names as reading reads it

Usage: reading entries stream [OPTIONS] --list <NAME>

Options:
      --list <NAME>
          The name of the reading list, such as to-read

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  reading entries stream --list to-read
          Print each entry of the to-read list as reading reads it

  reading entries stream --list to-read --json
          Print each entry of the to-read list as one JSON document on each line

Columns:
  position  The entry's position in the list, counting from 1.
  title     The title of the book.

Effects: read-only, closed-world.
Output: one row per line as each arrives, and --json prints one JSON document per line.
