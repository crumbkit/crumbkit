Open this reading list in your editor: $VISUAL, $EDITOR or vi

Usage: reading to-read edit [OPTIONS]

Options:
      --json
          Print the result as a JSON document on one line

      --fields <FIELD>
          Print only these comma-separated fields, in this order

      --long
          Add the long columns after the compact ones

      --full
          With --json, print every field of every row

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  reading to-read edit
          Open the to-read list in your editor

Effects: destructive, not idempotent, closed-world.
Writes: replaces existing data, without a version check.
