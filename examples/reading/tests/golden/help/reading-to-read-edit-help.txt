Open this reading list in your editor: $VISUAL, $EDITOR or vi

Usage: reading to-read edit [OPTIONS] [-- <EDITOR>...]

Arguments:
  [EDITOR]...
          The editor program and its arguments, in place of $VISUAL and $EDITOR

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  reading to-read edit
          Open the to-read list in your editor

  reading to-read edit -- nano
          Open the to-read list in nano

Effects: destructive, not idempotent, open-world, runs a program the caller names.
Writes: replaces existing data, without a version check.
Exit code: the command passes on the exit code of the editor.
