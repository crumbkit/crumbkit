Keep reading lists, and print the entries of each

Usage: reading [OPTIONS] <COMMAND>

Verbs
  where     Print the directory that holds reading's lists

Commands
  entries   Work with the entries of any reading list
  lists     Print the files of reading's lists
  commands  Explore reading's commands
  schemas   Explore the JSON documents that reading prints
  finished  Books finished this year
  to-read   Books to read next

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Topics: exit-codes. `reading help <TOPIC>` prints one.
