Print the JSON Schema of each document

Usage: reading schemas show [OPTIONS] <ID>...

Arguments:
  <ID>...  The ids of the documents that `schemas list` lists, separated by spaces

Options:
  -h, --help  Print help (see more with '--help')

Examples:
  reading schemas show reading/entries-list/v1

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `reading schemas show --help` describes them.
Next: reading schemas show --help explains each column.
