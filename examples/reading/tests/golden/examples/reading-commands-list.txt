PATH                    ABOUT
reading                 Keep reading lists, and print the entries of each
reading entries         Work with the entries of any reading list
reading entries list    List the entries of the reading list that --list names, in file order
reading entries stream  Print each entry of the reading list that --list names as reading reads it
reading entries set     Replace or append an entry of the reading list that --list names
reading entries export  Print the file of the reading list that --list names, as the file holds it
reading lists           Print the files of reading's lists
reading lists list      List reading's lists, each as one line with its about text
reading lists show      Print the file of each reading list named, each under a header when there are several
reading commands        Explore reading's commands
reading commands list   List a branch of reading's commands with their arguments and examples
reading schemas         Explore the JSON documents that reading prints
reading schemas list    List the JSON documents that reading prints, with a description of each
reading schemas show    Print the JSON Schema of each document
reading finished        Books finished this year
reading finished list   List the entries of this reading list, in file order
reading finished edit   Open this reading list in your editor: $VISUAL, $EDITOR or vi
reading to-read         Books to read next
reading to-read list    List the entries of this reading list, in file order
reading to-read edit    Open this reading list in your editor: $VISUAL, $EDITOR or vi
