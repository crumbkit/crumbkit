PATH                     ABOUT
shelf                    Browse a small catalogue of public-domain books
shelf books              Work with the books in the catalogue
shelf books list         List the books in the catalogue, in id order
shelf books show         Show the books with the given ids, in the order given
shelf books summarize    Describe the books with the given ids, or the whole catalogue, in one sentence
shelf books remove       Remove the books with the given ids from the shelf, so list and show skip them
shelf commands           Explore shelf's commands
shelf commands list      List a branch of shelf's commands with their arguments, examples and columns
shelf schemas            Explore the JSON documents that shelf prints
shelf schemas list       List the JSON documents that shelf prints, with a description of each
shelf schemas show       Print the JSON Schema of each document
shelf self               Review shelf's own use
shelf self usage         Report the patterns in shelf's usage log where callers waste effort
shelf self figures       Work with the figures of each command in shelf's usage log
shelf self figures list  List the figures of each command in shelf's usage log
Exit codes: 0, 1 and 2 are crumbkit's. `shelf help exit-codes` describes them.
