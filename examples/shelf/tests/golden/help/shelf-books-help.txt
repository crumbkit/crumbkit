Work with the books in the catalogue

Usage: shelf books [OPTIONS] <COMMAND>

Commands:
  list       List the books in the catalogue, in id order
  show       Show the books with the given ids, in the order given
  summarize  Describe the books with the given ids, or the whole catalogue, in one sentence
  remove     Remove the books with the given ids from the shelf, so list and show skip them

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')
