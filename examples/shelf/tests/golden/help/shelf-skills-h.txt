Give coding agents shelf's skill

Usage: shelf skills [OPTIONS] <COMMAND>

Commands:
  install  Install this tool's skills into each agent skills directory that exists
  check    Check that each installed copy of this tool's skills matches this build
  print    Print this tool's skill

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `shelf skills --help` describes them.
Next: shelf skills <COMMAND> -h
