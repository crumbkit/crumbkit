Review shelf's own use

Usage: shelf self [OPTIONS] <COMMAND>

Commands:
  usage    Report the patterns in shelf's usage log where callers waste effort
  figures  Work with the figures of each command in shelf's usage log

Options:
      --json
          Print the result as a JSON document

      --fields <FIELD>
          Print only these comma-separated fields, in this order

      --long
          Add the long columns after the compact ones

      --full
          With --json, print every field of every row

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')
