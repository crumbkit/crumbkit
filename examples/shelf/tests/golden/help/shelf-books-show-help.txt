Show the books with the given ids, in the order given

Usage: shelf books show [OPTIONS] <ID>...

Arguments:
  <ID>...
          The ids of the books to show, separated by spaces

Options:
      --from <FILE>
          Read the ids from this file, one id per line

      --json
          Print the result as a JSON document

      --fields <FIELD>
          Print only these comma-separated fields, in this order

      --long
          Add the long columns after the compact ones

      --full
          With --json, print every field of every row

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  shelf books show 2 5
          Show books 2 and 5

Columns:
  id      The book's id, unique within the catalogue.
  title   The book's title.
  author  The book's author.
  year    The year the book was first published.

Columns that --long adds:
  form  The book's literary form.

Effects: read-only, closed-world.
