Explore the JSON documents that shelf prints

Usage: shelf schemas [OPTIONS] <COMMAND>

Commands:
  list  List the JSON documents that shelf prints, with a description of each
  show  Print the JSON Schema of each document

Options:
      --json
          Print the result as a JSON document on one line

      --fields <FIELD>
          Print only these comma-separated fields, in this order

      --long
          Add the long columns after the compact ones

      --full
          With --json, print every field of every row

  -h, --help
          Print help (see a summary with '-h')
