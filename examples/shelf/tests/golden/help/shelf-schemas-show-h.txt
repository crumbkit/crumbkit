Print the JSON Schema of each document

Usage: shelf schemas show [OPTIONS] <ID>...

Arguments:
  <ID>...  The ids of the documents that `schemas list` lists, separated by spaces

Options:
  -h, --help  Print help (see more with '--help')

Examples:
  shelf schemas show shelf/books-list/v1

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `shelf schemas show --help` describes them.
Next: shelf schemas show --help explains each column.
