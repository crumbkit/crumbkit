Work with the figures of each command in shelf's usage log

Usage: shelf self figures [OPTIONS] <COMMAND>

Commands:
  list  List the figures of each command in shelf's usage log

Options:
      --json
          Print the result as a JSON document on one line

      --fields <FIELD>
          Print only these comma-separated fields, in this order

      --long
          Add the long columns after the compact ones

      --full
          With --json, print every field of every row

  -h, --help
          Print help (see a summary with '-h')

Next: shelf self figures <COMMAND> -h
