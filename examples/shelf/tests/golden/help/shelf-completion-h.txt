Set up shelf's completion in a shell

Usage: shelf completion [OPTIONS] <COMMAND>

Commands:
  install  Install shelf's completion where the shell loads it
  check    Check that shelf's installed completion file matches this shelf
  print    Print shelf's completion registration script for a shell

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `shelf completion --help` describes them.
