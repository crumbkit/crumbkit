Work with each run in shelf's usage log

Usage: shelf self runs [OPTIONS] <COMMAND>

Commands:
  list    List each run in shelf's usage log, grouped by session
  export  Print the records of shelf's usage log after a run, oldest first

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `shelf self runs --help` describes them.
