Browse a small catalogue of public-domain books

Usage: shelf [OPTIONS] <COMMAND>

Browse the catalogue
  books     Work with the books in the catalogue

Explore the commands
  commands  Explore shelf's commands
  schemas   Explore the JSON documents that shelf prints

Review how shelf is used
  self      Review shelf's own use

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Topics: catalogue, exit-codes. `shelf help <TOPIC>` prints one.
