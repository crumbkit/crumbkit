List the books in the catalogue, in id order

Usage: shelf books list [OPTIONS]

Options:
      --limit <N>  Print at most this many rows [default: 4]
      --all        Print every row
  -h, --help       Print help (see more with '--help')

Examples:
  shelf books list
  shelf books list --all

Global flags: --json, --fields <FIELD>, --long, --full. `shelf books list --help` describes them.
Next: shelf books list --help explains each column.
